# Data and Code Availability

Raw city-scale input data and derived paper-result tables are not included in this release repository.

The mobility data used in this study were sourced from Replica and are proprietary. These data cannot be redistributed under the applicable data-use agreement.

Processed PurpleAir PM2.5 sensor data may be shared with editors and reviewers for manuscript evaluation, subject to the relevant terms and access controls. PurpleAir data can also be recollected through the PurpleAir API.

GHAP baseline PM2.5 data and other auxiliary datasets used in the study are publicly available from their original providers.

A small de-identified or synthetic sample can be provided or included only for schema and smoke testing. Such a sample cannot reproduce city-scale estimates or paper results.

Full paper results require the licensed Replica population dataset and third-party PM2.5 and sensor inputs. Outputs generated from those inputs should be reviewed against all applicable data-use agreements before sharing.

Analysis code is available in this repository. The Bayesian diurnal-disaggregation method is also released as the Python package `diurnalize` for reuse by the community.
